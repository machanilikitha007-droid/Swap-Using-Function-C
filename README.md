# Swap Using Function in C

This program swaps two numbers using a user-defined function and
pointer parameters.

## File

swap_function.c

## Concepts Used

- Function definition
- Function call
- Pointer parameters
- Address operator
- Pass by address

## How to Run

gcc swap_function.c -o swap_function
./swap_function

## Sample Output

Enter two numbers: 10 25
Before Swap: 10 25
After Swap: 25 10
